# Loan Prediction Model

An end-to-end **machine learning–powered credit decision platform** that evaluates loan applications, performs risk analysis, and simulates macroeconomic stress scenarios.
Built with **XGBoost, Bagging, and Streamlit**, and deployed for real-time usage.

---

## Live Demo

👉 https://loan-prediction-model-omv9gjdqq365m2emj47kan.streamlit.app/

---

## Project Overview

This project simulates a **banking credit decision system** used to approve or reject loan applications.

It goes beyond a basic ML model by incorporating:

* **Multiple models (XGBoost & Bagging)**
* **Risk classification**
* **Stress testing (economic scenarios)**
* **Interactive dashboard (executive-level UI)**
* **Deployment on Streamlit Cloud**

---

## Key Features

### Machine Learning Engine

* XGBoost (high-performance boosting model)
* Bagging Classifier (ensemble stability)
* Pipeline with preprocessing (OneHotEncoding + imputation)

---

### Decision & Risk System

* Loan approval prediction (Approved / Rejected)
* Probability-based scoring
* Risk categorization:

  * 🟢 Low Risk
  * 🟡 Medium Risk
  * 🔴 High Risk

---

### Stress Testing Module

* Simulates economic downturn (income reduction)
* Shows impact on approval probability
* Helps analyze **credit sensitivity to macro conditions**

---

### Dashboard & Visualization

* Approval probability gauge chart
* Approval vs rejection donut chart
* Stress scenario comparison bar chart
* Clean, consulting-style UI

---

### Deployment

* Hosted on **Streamlit Cloud**
* Integrated with **GitHub**
* Fully interactive web application

---

## Tech Stack

* **Frontend/UI**: Streamlit
* **ML Models**: XGBoost, Bagging (scikit-learn)
* **Data Processing**: Pandas, NumPy
* **Visualization**: Plotly, Matplotlib
* **Model Serialization**: Joblib

---

---

## How It Works

1. User inputs applicant details
2. Selected ML model predicts approval probability
3. System assigns risk category
4. Stress testing simulates income shock
5. Dashboard visualizes decision & risk

---

## Business Value

This project mimics real-world banking systems by:

* Improving **credit decision transparency**
* Enabling **risk-based decision making**
* Supporting **scenario analysis (stress testing)**
* Providing **executive-level dashboards**
